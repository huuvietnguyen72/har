# Mã nhãn hoạt động

| Mã | Tiếng Việt (hiển thị) |
| --- | --- |
| `stand` | Đứng |
| `sit` | Ngồi |
| `lie` | Nằm |
| `walk` | Đi |
| `run` | Chạy |
| `stairs_up` | Lên cầu thang |
| `stairs_down` | Xuống cầu thang |
| `fall` | Té |

Model, cơ sở dữ liệu và API chỉ dùng mã tiếng Anh ở cột trái. Web app tự đổi sang tiếng Việt khi hiển thị.
